Barrier Share — Windows／Mac 雙向複製通用測試版

支援 Windows 10（1903 以上）／11 x64，以及 Apple Silicon Mac（macOS 15 以上）。
一次連接兩台，可自由搭配作主控端或接收端；兩台使用搜尋配對版，並在同一區網。
Windows 0.3.5 調整視窗排版與控制項，可搭配既有 Mac 0.3.4，配對可沿用。
Mac 固定簽章更新與 Windows 視窗更新相互獨立，無須每次同時更新兩台。

搜尋與配對
1. 停止舊版連線程式，再開啟新版。
   Windows：開啟 BarrierShare-Setup-0.3.5-x64.exe 安裝，再從開始功能表開啟 Barrier Share。
   更新前先從系統匣選「結束」；安裝程式會沿用同一位置，保留配對及設定。
   也可使用可攜 ZIP，解壓後雙擊 BarrierShare.exe。
   Mac：解壓縮後將 Barrier Share.app 放到「應用程式」，再開啟。
   Mac 測試版未公證，若被阻擋，請在「系統設定 → 隱私權與安全性」允許開啟。
2. 有實體滑鼠鍵盤的那台選「主控端」，另一台選「接收端」。
   兩邊都會自動搜尋同一區網內有開啟程式的電腦。主控端從「附近電腦」選接收端，按「邀請配對」。
   不需要填 IP，也不用複製 v2 指紋。
3. 接收端會顯示邀請；兩邊核對畫面上的 6 位數配對碼完全相同，才各按「相同，同意」。
   這會允許共用鍵盤滑鼠及雙向同步剪貼簿。只有一邊同意、拒絕或逾時都不會完成配對。
4. 配對完成後自動連線。之後只需開啟兩台程式；即使 IP 改變，也會重新搜尋並驗證保存的電腦身分。
   本版一次連接一台對端；配對另一台會替換目前對端。角色不限制檔案複製方向。
5. Mac 首次需允許「區域網路」、「輔助使用」及「輸入監控」。若系統列出 barriers／barrierc，也需允許。
   按「權限設定」可開啟設定；必要時重開程式。
   Windows 防火牆若詢問，允許 barrier-link.exe 和 barriers.exe 使用私人網路。

0.3.5 更新（Windows）
提供單一 EXE 安裝包，安裝到目前使用者的程式資料夾，不需要管理員權限；解除安裝保留配對及設定。
統一字級、欄位與按鈕尺寸；下拉選單有完整邊界，保留原生鍵盤操作。
加入按下與鍵盤焦點回饋，視窗縮放設定與背景鍵鼠程式分開處理。

0.3.4 更新（Mac）
修正設定頁等小尺寸圖示顯示彩色雜訊的封裝問題，沿用藍紫玻璃環造型。

0.3.3 更新（Mac）
Mac「診斷紀錄」會顯示目前 App 的實際權限狀態、執行位置與版本，沒有連上另一台也可檢查。
Mac 更新沿用固定簽章身分；從臨時簽章切換時仍可能需要重新授權一次。
更新前先結束舊程式，並使用相同安裝位置。CI 臨時簽章測試包不適用於保留權限的日常更新。

0.3.2 更新
重新設計藍紫玻璃環 App 圖示，適用 Mac Dock 與 Windows 程式／工作列／系統匣。
檔案讀寫改由背景執行，避免來源檔案開啟或磁碟回應緩慢時卡住鍵鼠與連線。
取消傳輸及關閉連線不等待磁碟；已取消的傳輸不會再次更新剪貼簿。

0.3.1 更新
修正 Windows 正式入口誤用介面測試模式，導致視窗開啟但搜尋服務未啟動。
加入 Mac App／Dock 與 Windows 程式／工作列／系統匣圖示；保留原有設定、憑證與配對。

如果找不到電腦
兩邊必須都開啟新版且角色不同；按「重新搜尋」。
「診斷紀錄」應出現「區網搜尋已啟動 · UDP/TCP 24801」，表示搜尋服務已實際啟動。
確認在同一區網、私人網路防火牆允許程式，且路由器沒有開啟訪客／用戶端隔離。
搜尋及配對使用 UDP／TCP 24801，鍵鼠與檔案使用 TCP 24800；不需要網際網路服務或路由器轉發。
本版使用 IPv4 區網搜尋，不跨子網／VPN。電腦名稱只供辨識，實際連線會檢查已保存的憑證。

暫停與解除
「暫停」停止搜尋、邀請與鍵鼠連線；「恢復連線」重新啟用。
「解除配對」停止連線並移除目前角色的信任，下次必須重新邀請並同意。
舊版憑證與本機設定會保留；首次改用搜尋版時仍需完成一次新的邀請流程，之後不必重配。

設定螢幕位置
在主控端選「接收端位置」：右、左、上、下。變更後會自動重新連線。
位置以主控端為準，接收端自動使用相反方向返回。

雙向複製檔案與資料夾
在來源電腦的 Finder／檔案總管選取檔案或資料夾並複製：Mac 用 ⌘C，Windows 用 Ctrl+C。
將游標移到另一台，等該台視窗顯示「已收到檔案」，在目標資料夾貼上：Mac 用 ⌘V，Windows 用 Ctrl+V。
兩個方向均可，原檔保留；可選多檔、整個資料夾（含空資料夾）。不需要拖曳，本版介面不啟用拖曳。
跨系統操作時使用目的端的快捷鍵：Mac 鍵盤上的 Command 對應 Windows 鍵，Control 對應 Ctrl；Windows 鍵盤的 Windows 鍵對應 Mac Command。
文字剪貼簿及鍵盤、滑鼠共享同時啟用。

檔案分成 64 KiB 區塊傳輸，逐檔 SHA-256 校驗；移除原本單檔 16 MiB 限制，大小使用 64 位元。
大檔案需等待傳送完成才可貼上。可用磁碟空間、檔案系統限制及區網速度仍適用。
接收端會先存一份暫存，貼上時再複製到目的地，因此需預留兩份空間。
來源在傳送時請勿修改。中斷連線或複製新的內容會取消未完成傳送，重連後請重新複製。
不支援符號連結、特殊檔案、Windows 不接受的檔名；一次選取最多 4096 個頂層項目、共 100 萬個項目、128 層目錄。
保留檔案內容與目錄結構；不保證保留 ACL、延伸屬性、時間戳記或執行權限。本版不是系統備份工具。

關閉視窗後仍在系統匣／Mac 選單列執行，選「結束」才停止。
接收檔案暫存會保留供貼上；按「暫停」後可按「清除暫存」。
清除會使尚未貼上的接收檔案失效，已貼到其他資料夾的檔案不受影響。
Windows 設定：%LOCALAPPDATA%\BarrierShare
Mac 設定：~/Library/Application Support/BarrierShare
日誌位於上述資料夾的 profile-server/server.log 或 profile/windows.log（Mac 為 mac.log）。

正式啟動驗證：實際開啟 Windows 正式視窗，確認主控／接收角色都啟動搜尋服務並回應 UDP 查詢。
搜尋與配對驗證：實際輔助程式的區網搜尋、TLS 短碼、雙方同意／拒絕、保存配對、重啟後自動重連、解除配對拒絕重連。
驗證範圍：自動化 Windows 原生剪貼簿與實際檔案總管貼上、雙向 TLS 傳輸、四個螢幕方向；Mac 原生檔案剪貼簿及視窗程式。
兩台實體 Windows／Mac 的完整操作仍需實機驗收；目前只提供 Windows x64 與 Mac arm64。
